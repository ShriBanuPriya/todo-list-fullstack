# To-Do List Full Stack Application

## About the Project
This is a beginner-friendly full-stack To-Do List application. Users can add, view, edit, delete, and complete tasks.

## Technologies Used
- **Frontend:** React, TypeScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose

## Features
- Add a new task
- View all tasks
- Edit task details
- Mark tasks as completed
- Delete tasks
- Store tasks in MongoDB

## Project Structure
- `client/` — React frontend
- `server/` — Node.js and Express backend

## How to Run the Project

### 1. Start the Backend
Open a terminal:

```bash
cd server
npm install
node server.js
```

### 2. Start the Frontend
Open another terminal:

```bash
cd client
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Database
The backend connects to a local MongoDB database named `todo_db`.

## Learning Goals
This project helped me practise React state, API requests, Express routes, CRUD operations, and MongoDB integration.
